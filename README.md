# LearnHub – Online Learning Management Platform

## Project Overview

LearnHub is a responsive web-based online learning management platform designed to provide accessible and high-quality educational opportunities. It enables learners to explore courses, enroll in programs, access video lessons, participate in discussion forums, interact with instructors, earn certificates, and track their learning progress through an intuitive and user-friendly interface.

## Key Features

- **Course Catalog & Listings:** Browse and explore a variety of programming and technology courses.
- **Course Enrollment & Payment:** User-friendly enrollment workflow with course pricing and payment interface.
- **Interactive Video Lessons:** Learn through structured video lectures with an embedded player.
- **Discussion Forums:** Encourage collaborative learning, student discussions, and peer Q&A.
- **Instructor Interaction:** Enable communication and engagement with instructors.
- **Certification of Completion:** Generate and download certificates upon course completion.
- **Progress Tracking & Reviews:** Monitor learning progress and explore or submit course reviews.
- **Responsive Design:** Optimized interface for desktops, tablets, and mobile devices.
- **User Authentication:** Login and registration interfaces for learners.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Seeja007/LearnHub-Online-Learning-Platform.git
cd LearnHub-Online-Learning-Platform
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Application Using VS Code Live Server

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension by Ritwick Dey.
3. Open `index.html` in the VS Code Explorer.
4. Right-click and select **Open with Live Server**.
5. The application will open in your default browser.

Local URL:

```text
http://127.0.0.1:5500/index.html
```
